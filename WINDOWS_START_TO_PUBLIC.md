# FinTwin-X — Windows PowerShell: clean local run to public link

Use PowerShell and run commands from the repository root unless a step says otherwise.

## A. One-time prerequisites

Install Git, Python 3.12, and Node.js 20 or 22. Check:

```powershell
git --version
py -3.12 --version
node --version
npm --version
```

## B. Clean Python setup

```powershell
py -3.12 -m venv .venv
Set-ExecutionPolicy -Scope Process -ExecutionPolicy RemoteSigned
.\.venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
python -m pip install -r requirements.txt
if (!(Test-Path .env)) { Copy-Item .env.example .env }
```

## C. Build the synthetic data, models and RAG index

```powershell
python -m data_generator.generate --users 500 --months 18 --seed 1
python -m pipelines.run_pipeline
python -m ml.train_all
python -m rag.ingestion.ingest_docs
```

## D. Install and verify the web app

```powershell
cd apps\web
if (Test-Path package-lock.json) { Remove-Item package-lock.json }
npm install
if (!(Test-Path .env.local)) { Copy-Item .env.local.example .env.local }
npm run typecheck
npm run build
cd ..\..
```

The new `package-lock.json` generated by `npm install` should be committed to GitHub.

## E. Run the automated checks

```powershell
python -m pytest tests -q
```

Do not continue to public deployment if the tests or web build fail.

## F. Start locally

Terminal 1:

```powershell
Set-ExecutionPolicy -Scope Process -ExecutionPolicy RemoteSigned
.\.venv\Scripts\Activate.ps1
python -m uvicorn apps.api.main:app --host 0.0.0.0 --port 8000 --reload
```

Terminal 2:

```powershell
cd apps\web
npm run dev
```

Open:

- `http://localhost:3000`
- `http://localhost:8000/health`
- `http://localhost:8000/docs`

Check every product page: Command Center, Cash Intelligence, Risk Engine, Scenario Lab, AI Copilot, and Model Operations.

## G. Quick API checks

```powershell
Invoke-RestMethod http://localhost:8000/health | ConvertTo-Json -Depth 8
Invoke-RestMethod http://localhost:8000/users/8/overview | ConvertTo-Json -Depth 8
Invoke-RestMethod -Method Post -Uri http://localhost:8000/agent/chat -ContentType "application/json" -Body '{"user_id":8,"question":"hi"}' | ConvertTo-Json -Depth 8
```

The three calls should return HTTP 200.

## H. Push to GitHub

First create an empty public repository named `fintwin-x` on GitHub. Do not initialize it with another README, `.gitignore`, or license. Then:

```powershell
git init
git add .
git status
git commit -m "feat: publish FinTwin-X v2 portfolio demo"
git branch -M main
git remote add origin https://github.com/YOUR-USERNAME/fintwin-x.git
git push -u origin main
```

If Git asks for your identity:

```powershell
git config user.name "YOUR NAME"
git config user.email "YOUR GITHUB EMAIL"
```

Then repeat `git add .`, `git commit ...`, and `git push -u origin main`.

## I. Deploy free on Render with one URL

1. Sign in to Render.
2. Choose **New + -> Blueprint**.
3. Connect GitHub and select the `fintwin-x` repository.
4. Render reads the repository-root `render.yaml`.
5. Create/apply the Blueprint.
6. GitHub Actions checks the backend and web build; Render is configured to deploy after checks pass.
7. When the deployment is Live, open the generated `https://<service-name>.onrender.com` URL.
8. Verify `<url>/health` and `<url>/docs` as well.

The base `onrender.com` URL is the single link to place in LinkedIn.

## Free-tier note

The public Render configuration is a portfolio/demo deployment. It disables SHAP in that environment and uses the built-in surrogate explanation to reduce memory usage. Local/full runs keep SHAP enabled by default. A free Render service can also sleep after inactivity, so the first visit after a long idle period can be slower while the service wakes up.
